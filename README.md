# Travel Plan Page

把自己的旅行計劃快速整理成一個適合手機檢視和分享的旅行網頁。

這是一個 AI-Friendly 的輕量旅行網頁模板。\
你可以把航班、住宿、每日行程、門票、租車等旅行資料交給 Agent，由它按照現有模板生成第一版頁面。

> 預設優先快速生成，先得到一個完整可用的網頁底板，再根據自己的需求繼續修改。

---

## 功能

目前頁面主要包含：

- ✈️ 航班資訊
- 🗺️ 旅行路線地圖
- 📅 每日行程 Timeline
- 🎫 門票 / PDF
- 🚗 租車與自駕資訊
- ✅ To Do
- 💰 多人旅行記賬、分攤、統計和最終賬單結算

不需要的模組可以關閉。

---

## 如何使用

把專案提供給支援 Skill / Agent 工作流的 AI，同時上傳自己的旅行資料。

可以直接告訴它：

> 我的旅行資料在這裡，請基於這個 Skill 幫我生成一個旅行頁面。

Agent 會先閱讀和整理你的旅行計劃，確認需要的模組以及明顯缺失的資訊，然後生成第一版網頁。

建議儘量提供已經確定且相對完整的旅行資料，包括日期、地點、航班、住宿、每日行程、交通、門票等。

由於 Agent 需要先閱讀、理解並整理旅行計劃，行程天數越多、涉及的城市或國家越多、資料越複雜，生成時間也可能相應增加。

第一版的目標是：

> 快速把已經確定的旅行資訊整理成一個結構統一、視覺完整、可以繼續修改的網頁底板。

## 關於地圖

地圖是這個專案裡比較特殊的一部分。

如果讓 AI 針對每一次旅行、每一個國家或地區重新設計一張完整地圖，通常會明顯增加生成時間，也會消耗更多 Token，同時不同生成結果之間的視覺一致性也比較難保證。

所以在預設的輕量生成流程中，不會讓 AI 每次重新設計地圖。

專案裡已經準備了一組風格統一、相對精美的地圖模板。

生成網頁時，會根據旅行地點和路線選擇合適的模板，再加入使用者自己的地點、路線和行程資訊。

基礎版本更關注：

> 路線清晰、整體好看、不同頁面之間保持統一。

如果你對地圖有更高要求，也可以在第一版頁面完成後，再單獨讓 AI 對地圖繼續修改和完善。

## 本地預覽

生成完成後，可以在專案目錄執行：
```
npm run preview
```

如需重新生成地圖或檢查當前資料：
```arduino
npm run build:map
npm run validate
```

## 分享網頁

預設生成的是本地可執行版本。

如果之後希望分享給朋友，可以繼續部署到：
```
本地網頁
↓
GitHub
↓
Cloudflare Pages
↓
[可選] Cloudflare D1
```

Cloudflare D1 只在需要多人 / 多裝置共享記賬、To Do、Ticket 等資料時才需要。

## 資料與隱私

旅行資料會寫入你自己的專案中。

如果頁面中包含酒店地址、訂單資訊、門禁資訊、聯絡方式等內容，請根據自己的分享範圍決定是否保留。

不要把 API Token、Private Key、資料庫密碼等開發金鑰提交到公開 GitHub 倉庫。

## About

這個專案最開始是我為自己的旅行製作的一個網頁。

後來把航班、每日行程、地圖、門票、To Do 和多人記賬逐步放進了同一個頁面，並整理成現在這套可以被 AI 快速複用的輕量模板。

希望它也能幫助你更方便地整理自己的旅行計劃。
